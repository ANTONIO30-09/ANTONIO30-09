## 🥇 Sobre mí

Soy **Antonio Vicente García Corrales**, estudiante de **Ingeniería de Sistemas (6to semestre)** en Bolivia. Construyo proyectos aplicados de **Machine Learning e IA generativa** con recursos limitados — desde modelado estadístico para predicción deportiva hasta herramientas de IA para ingeniería — además de desarrollo web full stack y automatización.

## 🚀 Lo que hago

- 🤖 **Machine Learning / IA aplicada**: modelos estadísticos (Poisson, Dixon-Coles), simulación Monte Carlo, integración de LLMs (Gemini API), experimentación con modelos locales (Ollama)
- 🌐 **Desarrollo full stack**: React + Vite + TypeScript en frontend, FastAPI + Pydantic en backend
- 🗄️ **Bases de datos**: MySQL, SQL Server, MongoDB
- ⚙️ **Automatización**: PowerShell, scripts de terminal, entornos de desarrollo personalizados en Linux

## 📌 Proyectos Destacados

- 🔌 **Circuit-AI** — Genera diagramas de circuitos electrónicos a partir de lenguaje natural, pensado para prácticas de laboratorio (PIC16F877A, ESP32, sensores). FastAPI + Gemini API + React/Konva.js.
- ⚽ **PREDICCIÓN** — Sistema de predicción de resultados de fútbol para el Mundial 2026: modelo bivariado de Poisson, ajuste Dixon-Coles y simulación Monte Carlo; v2 con fuerza de equipos basada en ELO.
- 🚌 Sistema de gestión (rutas / administración / datos)
- 📦 Gestión de pedidos/entregas (CRUD + BD)
